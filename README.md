# Acção

Ferramenta pessoal para descobrir e analisar ações.

- **Descobrir ações:** filtra por tipo de negócio (34 tipos), dividendos, tamanho, oscilação do preço e preço máximo.
- **Analisar:** nota de 0 a 100 em 4 camadas (qualidade, avaliação, sinais de mercado e riscos), com as regras de cada nota à vista.

## Como usar

1. Abre a página (GitHub Pages).
2. Carrega em "Sem chave", no topo, e cola a tua chave da API da Financial Modeling Prep (plano gratuito).
3. Escreve um código (ex.: AAPL) ou usa o separador "Descobrir ações".

A chave fica guardada só no teu navegador; não está neste repositório.

> Apoio à investigação pessoal. Não é recomendação de investimento.
